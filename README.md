# Telegram Sender Bot

Бот для автоматической рассылки сообщений в Telegram чаты.

## Возможности

- 🔐 Авторизация в Telegram аккаунте
- 📝 Создание рассылок с текстом, фото или видео
- 🎯 Выбор нескольких чатов для отправки
- 🔍 Поиск чатов по названию
- ⏰ Настройка интервалов: раз в час, раз в день или кастомный интервал
- 📋 Просмотр активных рассылок

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Заполните `.env` файл:
- `BOT_TOKEN` - токен вашего бота от @BotFather
- `ADMIN_ID` - ваш Telegram ID
- `API_ID` и `API_HASH` - получите на https://my.telegram.org

## Запуск

```bash
python main.py
```

## Использование

1. Запустите бота командой `/start`
2. Войдите в свой Telegram аккаунт
3. Создайте рассылку, выбрав чаты и интервал отправки
4. Бот будет автоматически отправлять сообщения по расписанию
